# 州桥遗址（s15）

- 别名：州桥
- 所在城市：开封
- 年代：宋
- 类型：古建筑

## 摘要
北宋御街跨越汴河之桥，出土明代巨幅石雕。

## 简介
州桥位于开封城区御街遗址中轴线上，是北宋东京城连接宫城与内城的水陆要冲，唐代始建时名汴河桥，北宋时称州桥。《东京梦华录》记其为御街要段、夜市所在。遗址经持续发掘，暴露出州桥桥体、汴河河道、码头与历代路桥叠压层，完整呈现黄河泛滥背景下开封“城摞城、路摞路、桥摞桥”的地层。

## 考古发现
1984年与2000年局部探明桥位。2018至2022年河南省文物考古研究院主持全面发掘，清理出州桥桥体、汴河河道及两岸明代“祥云海兽纹”巨幅石雕壁（为我国同类考古发现中规模罕见），出土宋、金、明、清各代陶瓷、钱币与建筑构件，实证了北宋东京城中轴线位置。

## 历史脉络
州桥是研究北宋东京城布局的定轴点，河道与桥体叠压层直观记录了黄河与汴河的水文变迁，是古代城市与水患长期共存关系的典型案例。汴河曾把东南漕运的粮食财货送入京师，州桥一带正是这条水路上的要冲。
