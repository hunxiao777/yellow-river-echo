# 郑州商城遗址（s10）

- 别名：郑州商城
- 所在城市：郑州
- 年代：夏商
- 类型：都城遗址

## 摘要
商代前期都城，出土杜岭方鼎。

## 简介
郑州商城遗址发现于1950年，位于郑州老城区，由商代前期城垣、宫殿区与护城壕等构成。内城垣周长约七公里，南、北段夯土至今仍高数米。城内外发现铸铜、制陶作坊，以及张寨南街等处青铜器埋藏坑。学界多认为它是商代前期的隞都或亳都一类都邑，是夏商文化过渡之后已知最早的大型王都级城址。

## 考古发现
1950年代发现后，河南省文物管理部门与中国社会科学院考古研究所多次发掘勘探。1974年张寨南街出土两件大型铜方鼎，即杜岭方鼎，为现存最大的早商方鼎类青铜器；另出土饕餮纹铜尊、白陶、原始瓷与金饰件等，城内多处探明宫殿夯土基址。

## 历史脉络
郑州商城把商代前期国家的历史落实到考古遗存上，证明约公元前十六世纪黄河中游已出现大规模都邑与高度分工的官营手工业，是夏商周断代与商前期都城制度研究的核心坐标。城垣夯土与杜岭铜鼎等发现，共同印证了郑州作为商代前期政治中心的地位。
