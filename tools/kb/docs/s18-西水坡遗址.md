# 西水坡遗址（s18）

- 别名：西水坡
- 所在城市：濮阳
- 年代：仰韶、龙山
- 类型：聚落遗址、墓葬群

## 摘要
仰韶文化墓葬现蚌塑龙虎图案，称“中华第一龙”。

## 简介
西水坡遗址位于濮阳市区、黄河故道之畔，包含仰韶、龙山、东周、两汉时期叠压遗存，最重要的是仰韶文化墓葬群。1987年发掘的M45墓坑主人两侧以蚌壳摆塑龙、虎图案，年代距今约六千四百年，被称为“中华第一龙”，同组遗迹还有龙虎驮人、鹿等蚌塑，被认为蕴含原始天文星象与神权观念。

## 考古发现
1976年调查发现，1987至1988年河南省文物考古研究所为配合基建发掘。除蚌塑龙虎外，还出土彩陶钵、石刃、玉饰与成组灰坑，明确了三组蚌塑龙虎图案的排列关系；后续保护工程揭露了仰韶墓地与龙山时期壕沟。

## 历史脉络
蚌塑龙虎图证明黄河下游仰韶时代已有成熟的龙形象与原始天文意识，把中华龙文化的实物年代大幅提前，也为研究史前礼俗起源及河洛与海岱文化交汇提供了关键证据。龙的形象和龙虎陪衬的埋葬观念，在后世逐渐演化为华夏文化中的龙崇拜。
