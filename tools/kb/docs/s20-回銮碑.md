# 回銮碑（s20）

- 别名：澶渊之盟御书碑
- 所在城市：濮阳
- 年代：宋
- 类型：古建筑

## 摘要
澶渊之盟后宋真宗回銮途中驻跸澶州所立的御书碑。

## 简介
回銮碑位于濮阳市老城区，即北宋澶州所在地。景德元年（1004年）宋辽订立澶渊之盟，宋真宗在回銮途中驻跸澶州，立碑记其事，后世称为回銮碑。碑身高大，御书字迹大部可辨，是澶渊之盟这一重大历史事件少见的地面实物见证，现为全国重点文物保护单位。它与附近的戚城遗址等共同构成濮阳的历史遗迹序列。

## 考古发现
碑体现存市内保护院落中，历代摹拓与著录见于河南金石文献。文物部门对碑身做过形制测量与风化病害调查，碑周边勘察出宋代建筑相关遗物；碑文可与《宋史》真宗本纪的记载对照阅读。

## 历史脉络
澶渊之盟后宋辽约为兄弟之国，北边防务长期松弛，河朔一带相对安定，黄河两岸往来贸易增多。一方御书碑连接了寇准主战、真宗亲征与盟成回銮诸史事，是北宋与辽关系史的实物见证。
