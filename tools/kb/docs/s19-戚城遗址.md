# 戚城遗址（s19）

- 别名：戚城
- 所在城市：濮阳
- 年代：周
- 类型：都城遗址

## 摘要
春秋齐桓公会盟诸侯的“盟戚”之地。

## 简介
戚城遗址位于濮阳市区、黄河故道旁，为东周至汉代沿用的一处城邑。据《春秋》《左传》记载，鲁僖公元年（公元前659年）齐桓公与诸侯会盟于此，史称“盟戚”，是齐桓公称霸过程中的重要事件。考古探明城址平面近方形，夯土城墙残存并设有标识，城内及附近历年出土东周至汉代青铜器、陶器与货币，现为戚城文物景区。

## 考古发现
二十世纪七十年代以来文物部门多次调查勘探，确认城墙、门址与城内文化层堆积，探出战国至汉代居住与作坊遗迹，周边出土鬲、鼎残件、钱币等遗物；近年完成遗址保护展示工程，城垣断面与会盟纪念石刻供人凭吊。

## 历史脉络
戚地位处晋卫之际、黄河要渡，诸侯会盟事件见于《左传》，是春秋争霸史的直接地标。城址堆积与河道变迁互为表里，为研究黄河故道演变与东周城邑分布提供了样本。戚城残墙至今保存在景区中，是春秋会盟地理的直接坐标。
