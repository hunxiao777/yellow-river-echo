# 偃师商城遗址（s05）

- 别名：偃师商城
- 所在城市：洛阳
- 年代：夏商
- 类型：都城遗址

## 摘要
早商大型城邑，或即商汤伐夏后所都之亳。

## 简介
偃师商城遗址位于洛阳市偃师城区，洛河与黄河之间的台地上，1983年发现。城址由大城、小城和宫城组成，平面近长方形，宫城内发现多组殿堂院落、门塾和仓储遗迹，布局经过统一规划。它是现存年代最早、保存最完整的商代城址之一，学界多认为与商汤灭夏后营建的都邑有关，是夏商之际的历史坐标。

## 考古发现
1983至1984年中国社会科学院考古研究所开始发掘，此后持续勘探清理。宫城区内发现殿堂基址、院落、排水管道和大口尊类储物遗迹，城墙与城门址均已探明，出土陶器、石器、骨器、铜器及海贝、金箔等遗物。

## 历史脉络
偃师商城始建年代与二里头文化衰亡相接，反映商初经略西部、控扼夏遗民的格局，为夏商分界和商代前期都城制度提供了直接证据，是夏商周断代工程年代学研究的重要支点。城墙、城壕与城内道路网也因此成为早商城邑考古研究的参照。
