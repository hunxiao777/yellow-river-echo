# 仰韶村遗址（s01）

- 别名：仰韶村
- 所在城市：三门峡
- 年代：仰韶
- 类型：聚落遗址

## 摘要
仰韶文化命名地，中国第一个被命名的史前考古学文化。

## 简介
仰韶村遗址位于三门峡市渑池县仰韶村，地处黄河南岸台地，是仰韶文化的命名地。1921年安特生在此试掘，首次确认中国存在新石器时代彩陶文化，此后以遗址命名了仰韶文化。遗址面积约30万平方米，包含仰韶早期、庙底沟期和龙山时期遗存。它把中国史前研究带入有实物证据的阶段，在中国考古学史上具有起点意义。

## 考古发现
1921年安特生主持试掘，出土彩陶片、石斧、骨器等。1959年中国科学院考古研究所再次发掘，明确了仰韶文化与龙山文化的地层关系。2020至2022年河南省文物考古研究院等单位系统发掘，发现壕沟、墓地，出土彩陶、玉器、骨针和丝织品遗存。

## 历史脉络
仰韶村发掘被视为中国现代考古学的开端，仰韶文化由此成为第一个命名的中国史前文化。遗址证明约七千年至五千年前黄河中游已有发达的粟作农业聚落，是中华文明探源工程的起点性坐标。
