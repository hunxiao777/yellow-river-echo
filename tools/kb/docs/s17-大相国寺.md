# 大相国寺（s17）

- 别名：相国寺
- 所在城市：开封
- 年代：宋
- 类型：古建筑

## 摘要
始建于北齐、唐代赐额的北宋皇家寺院。

## 简介
大相国寺位于开封市中心，始建于北齐天保六年（555年），唐睿宗景云年间因纪念其曾任相王封号而赐名“大相国寺”。北宋时它是京城首寺，承担译经、祈祷与接待外来僧使等职能，每月定期开放的寺市商贾云集。其后屡因黄河水患圮毁并重建，现存寺院多为清代重建格局，中轴线上有天王殿、大雄宝殿、八角琉璃殿等建筑。

## 考古发现
寺区勘察证实“城摞城”序列：二十世纪九十年代在寺内地下数米处发现北宋寺院地面与建筑基址，现为寺内地下展陈的依据；八角琉璃殿内清代千手千眼观音像以整根木料雕成，寺内历代碑刻、石狮为重要传世实物。

## 历史脉络
作为北宋皇家寺院，大相国寺见证汴京佛教的鼎盛与寺市繁荣，《水浒传》中鲁智深倒拔垂杨柳的故事即以此寺为背景。地下宋寺地面与现存清代寺院的上下叠压，是开封城市延续性的典型标本。
