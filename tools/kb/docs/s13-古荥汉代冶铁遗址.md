# 古荥汉代冶铁遗址（s13）

- 别名：古荥冶铁遗址
- 所在城市：郑州
- 年代：汉唐
- 类型：手工业遗址

## 摘要
汉代河南郡官营冶铁中心，同期罕见的巨型炉基。

## 简介
遗址位于荥阳市北郊，1959年发现，为汉代规模巨大的官营冶铁工场，出土陶器上的“河一”戳印铭文可证其属河南郡铁官第一冶。作坊区可辨出炉房、锻打、淬火、仓储等功能分区，两座椭圆形大熔炉炉基保存完好，最大炉基近八平方米，是迄今所见汉代最大的冶铁炉，反映汉代冶铁规模居当时世界前列。

## 考古发现
1959至1961年河南省文物管理部门发掘，清理两座大炉基及积铁、陶模、铁工具，发现煤饼遗存，证明当时已部分用煤作燃料；出土铁器有铲、锸、刀等农工用具与带“河一”陶文的陶器。遗址上建有炉基原状保护展厅。

## 历史脉络
这里是汉武帝盐铁官营政策在河南郡的落地实例，大熔炉容量、铸铁脱碳钢等工艺使汉代铁农具得以大量普及，遗址在世界冶金史上被视为汉代冶铁技术的标杆。如此集中的铁器生产，为汉代农具普及和垦荒拓田提供了物质条件。
