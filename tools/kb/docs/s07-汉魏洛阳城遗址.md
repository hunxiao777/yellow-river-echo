# 汉魏洛阳城遗址（s07）

- 别名：汉魏故城
- 所在城市：洛阳
- 年代：汉唐、周
- 类型：都城遗址

## 摘要
东汉曹魏西晋北魏等王朝都城，沿用约六百年。

## 简介
汉魏洛阳城遗址位于洛阳市区东侧洛河北岸。公元25年刘秀定都于此，此后曹魏、西晋、北魏先后以此为都，城址沿用约五百六十年，是古代沿用时间最长的都城之一。北魏时城内外佛寺林立，洛阳是当时北方的政治文化中心。城垣、宫殿、太学、明堂与里坊遗存丰富，是从汉到唐都城制度演变的关键环节。

## 考古发现
1962年中国科学院考古研究所勘察全城，之后历次发掘明确了不规则形城垣、宫城多期叠压格局和北魏太极殿大型夯土基址。1997年在城北宫殿区出土汉代金缕玉衣，另有大量瓦当、碑刻残件出土。

## 历史脉络
此城历经东汉创业、党锢之祸、曹魏禅代、西晋统一与北魏孝文帝汉化诸事件，其宫城居中、单一轴线布局开后世隋唐都城之先声，是研究汉魏至北魏政治制度与城市规划的核心遗址。
