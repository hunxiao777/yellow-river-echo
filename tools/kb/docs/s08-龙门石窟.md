# 龙门石窟（s08）

- 别名：龙门
- 所在城市：洛阳
- 年代：汉唐
- 类型：石窟寺

## 摘要
北魏至唐代开凿的佛教石窟群，世界文化遗产。

## 简介
龙门石窟位于洛阳市南伊河两岸的龙门山与香山崖壁上，开凿始于北魏孝文帝迁都洛阳前后（约494年），历经东魏、北齐、隋、唐、北宋四百余年营造，现存窟龛两千三百余个、造像十万余尊、碑刻题记两千八百余品。奉先寺大卢舍那像龛是唐代雕塑的代表作，龙门是中国现存规模最大的石刻佛教艺术群之一，2000年列入世界文化遗产。

## 考古发现
二十世纪三十年代起学界开展系统调查与录档。1961年公布为全国重点文物保护单位，此后龙门文物研究机构完成窟区测绘、排水加固与造像清理。考古工作厘清了各窟开凿次序与纪年题记，奉先寺南侧近年经发掘确认了唐代构建筑基址。

## 历史脉络
龙门开凿与北魏迁都洛阳、孝文帝汉化改革直接相关，唐代由皇室持续营建，魏碑体的“龙门二十品”与《伊阙佛龛之碑》是书法史名作，窟像风格演变见证了中国古代佛教艺术本土化的进程。
