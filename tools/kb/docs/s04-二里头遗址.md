# 二里头遗址（s04）

- 别名：二里头
- 所在城市：洛阳
- 年代：夏商
- 类型：都城遗址

## 摘要
夏代中晚期都城性邑址，中国最早的城市宫城。

## 简介
二里头遗址位于洛阳市偃师区洛河南岸，面积约300万平方米，年代约公元前1750至前1520年。遗址发现中国最早的城市主干道网、宫城和多进院落宫殿基址（一号、二号宫殿），以及青铜冶铸、绿松石手工业作坊。多数学者认为它是夏代中晚期都城，可能是文献中的夏邑。它标志着东亚大陆最早王朝文明形态的形成。

## 考古发现
1959年徐旭生调查发现，此后中国科学院考古研究所及中国社会科学院考古研究所持续发掘近七十年。代表性出土物有绿松石龙形器（用两千余片绿松石拼合）、青铜爵与鼎、陶龙、漆器和白陶，宫室基址与井字形道路系统均已探明。

## 历史脉络
二里头的宫城制度、礼器组合和官营手工业，显示夏代已出现成熟的国家机器，是探索夏文化和夏商分界的核心遗址，也是中华文明起源与早期国家研究中最关键的实证之一。以青铜礼器和绿松石器为代表的出土物，显示当时已形成为统治服务的礼仪系统。
