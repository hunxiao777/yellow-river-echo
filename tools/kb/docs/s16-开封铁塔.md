# 开封铁塔（s16）

- 别名：铁塔
- 所在城市：开封
- 年代：宋
- 类型：古建筑

## 摘要
北宋琉璃砖塔，因色如铁得名，历经千年不倒。

## 简介
铁塔位于开封市东北铁塔公园内，建于宋皇祐元年（1049），原为北宋开宝寺内所建佛塔。塔八角十三层，高约55米，全塔以褐色琉璃砖瓦砌筑、仿木构斗拱，远观如铁，故民间称铁塔。历经近千年水患、战火与地震仍基本完好，是中国现存最高、最古老的琉璃砖塔之一，素有“天下第一塔”之称。

## 考古发现
塔本体以测绘与修缮为主：二十世纪五十年代起多次修葺，查明了琉璃砖砌法、塔心室与基座结构；塔面砖雕有佛像、飞天、力士、麒麟等纹样。因黄河泥沙长期淤高地面，塔基下部已埋入地下数米。

## 历史脉络
铁塔建于北宋东京繁盛之世，集宋代琉璃烧造与砖石结构技术之大成。它与开封共同经历黄河屡次决口、城毁而复建的循环，塔基被淤埋的高度本身就是黄河水患史的现场记录。清代开封十景中的“铁塔行云”，说的就是这座塔。
