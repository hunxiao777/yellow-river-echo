# 王城岗遗址（s09）

- 别名：王城岗
- 所在城市：郑州
- 年代：龙山、夏商
- 类型：聚落遗址

## 摘要
龙山晚期城址，被不少学者视为夏禹所居阳城。

## 简介
王城岗遗址位于登封市东南、颍河与五渡河交汇的高地上，属龙山文化晚期至新砦期。考古发现东西并列的两座夯土城址及城内高台建筑、墓葬群，文化年代正处龙山向二里头过渡阶段。因其地理位置与文献夏人活动区吻合，不少学者主张它就是“禹居阳城”，是探索夏文化最早期的关键遗址之一。

## 考古发现
1959至1960年文物普查发现，1975至1981年河南省文物考古研究所多次发掘确认城址；2002年后北京大学等单位重新发掘，出土龙山晚期白陶、玉饰和小型铜容器残片等高等级遗物，为早期青铜礼器研究提供线索。

## 历史脉络
王城岗城址说明龙山晚期黄河中游已出现城邑级公共权力，若与文献“夏都阳城”对应成立，它即夏王朝肇始之都；其兴废过程也反映了夏初政治中心的转移，与夏商周断代研究高度相关。
