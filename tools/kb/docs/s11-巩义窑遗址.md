# 巩义窑遗址（s11）

- 别名：巩县窑
- 所在城市：郑州
- 年代：汉唐
- 类型：窑址

## 摘要
汉唐名窑，唐三彩与白瓷的重要产地。

## 简介
巩义窑遗址分布在巩义市西部的白河、孝义河畔，是汉唐至北宋时期北方重要瓷窑群，隋唐时因临近东都洛阳成为贡瓷产地。窑区遗址规模大、延续长，唐代以生产白瓷、黑釉与三彩闻名，被认为是唐三彩的主要产地之一，也是目前所知较早烧制青花瓷的窑口，在陶瓷史上占有枢纽地位。

## 考古发现
二十世纪五十年代文物部门调查登记窑址。1972年及1995至1999年、2005年前后河南省文物考古机构多次发掘，清理出窑炉、作坊、地层与三彩窑具，确认大、小窑店等窑区位置，出土白瓷碗盘、三彩残片及青花标本。

## 历史脉络
巩义窑白瓷质量在唐代备受推崇，窑址出土的青花标本是中国早期青花瓷源流研究的关键证据，所产瓷器沿丝绸之路外销，西亚地区曾发现同类三彩与白瓷残片，见证唐代手工业与贸易的发达。
