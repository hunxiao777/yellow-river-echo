# 沿河课程

站内手作与通识课程目录。

## 仰韶彩陶的鱼纹怎么画（c01）
- 分类：手作
- 难度：入门
- 时长：18 分钟
- 关联遗址：s01
- 简介：从揉泥开始，在盆形坯上把鱼纹画到位，再阴干入窑。

步骤：
1. 练泥制坯：陶泥反复揉压，把里边的气泡挤干净，墩成泥饼后围出盆形，接口抹平。坯子不能太湿，太湿待会儿一下笔就洇成一团。
2. 起稿分区：用细炭条在盆的肩腹部定出纹样带，先把上下两道弦线拉直，鱼形放在中间那段，留出首尾相接的位置，别把带画满。
3. 勾线成形：矿物颜料调稀，笔从肩线起头，鱼身一条弧线走到底。彩陶的线条讲究一次画完，来回描补看着就僵，史前的画法也这样。
4. 填彩留白：鱼鳞和鳍用黑彩点出来，红陶胎大面积留着不动。仰韶彩陶靠的是黑彩与红胎的对比，填得太满反而闷，气眼要留够。
5. 阴干入窑：画好的坯子放阴凉处晾几天，干透再进窑。升温太快会让颜料层起壳，颜色发灰发暗，这一步确实没有捷径可走。

资料来源：仰韶文化博物馆公开展陈说明整理

## 龙山黑陶的快轮拉坯（c02）
- 分类：手作
- 难度：进阶
- 时长：22 分钟
- 关联遗址：s09
- 简介：薄胎黑陶靠轮子说话，从定中到压光，五步走一遍。

步骤：
1. 练泥去芯：泥料要淘得细，反复踩揉到没有硬块，撕开断面看到均匀纹理才算好。黑陶的胎薄，掺了砂粒拉到一半就会穿。
2. 上轮定中：泥团摔在轮盘正中心，转速保持匀，湿手压住顶部往下带。这一关定不居中，手一抬器壁就一面厚一面薄。
3. 开孔拉升：拇指从中心开孔，两手贴着壁慢慢往上带，一圈只提一两毫米。拉到高度再收尾口，快轮留下的匀整感全在这几步。
4. 修坯压光：坯子晾到软硬合适时上架修形，竹刀刮掉余泥，再用骨片把表面压出亮面。龙山器物上的网格纹也是这时刻的。
5. 阴干装窑：慢慢阴干，裂多半出在这一步。装窑后用还原焰渗碳，出窑的器物才带那种深灰近黑的金属光，不是刷上去的。

资料来源：登封市博物馆公开展陈说明

## 一只铜爵的范铸过程（c03）
- 分类：手作
- 难度：进阶
- 时长：25 分钟
- 关联遗址：s04
- 简介：泥模、外范、铜芯怎么合到一起，铜水倒下去才知道。

步骤：
1. 塑出泥模：先用泥把爵的样子塑出来，前流后尾、一侧的鋬和三条尖足都定在这件上。模上不留花纹，纹要另外在范上做。
2. 翻制外范：细泥片贴覆在模上压紧，分块揭下阴干修整。范面里侧刻上乳钉和带状纹，这些凹印最后就是器物表面的花。
3. 制芯合范：用泥芯撑出器壁的厚度，芯与外范之间留一层空当，铜水就灌在这里。范块合拢后外面箍紧，还要埋进土里固定。
4. 浇注铜水：青铜化到温度后一次注满，手不能停。冷下来就把外范打碎取器，范是一次性的，不破范看不见里面的活成不成。
5. 修整打磨：剪掉浇口和多余的铜，砺石顺着器身磨。三足要锉平才站得住，磨过的地方氧化后颜色才匀，这一步古人做得很实在。

资料来源：二里头夏都遗址博物馆公开展陈说明

## 唐三彩的配釉与施釉（c04）
- 分类：手作
- 难度：入门
- 时长：15 分钟
- 关联遗址：s11
- 简介：半截釉交给窑火，颜色怎么走全凭这几道手法。

步骤：
1. 先烧素胎：成型晾透的胎先低温烧一遍，把水分和气孔去掉，之后吃釉才匀。素胎拿在手里应当轻，敲一下声音不散。
2. 调釉配色：釉里加铅做助熔，再拿铜、铁、钴这些金属氧化物调出绿、黄和带蓝的白。配好的釉调成糊状，静置把泡排掉。
3. 上釉手法：刷、点、淋几种手法可以并用，同一处叠上两三种釉。下刷之前要先想好釉往下流的路子，横着刷就全乱了。
4. 垂釉阴干：施完竖着放，让多余的釉自己往下走一段。这一步决定入窑后流釉的长短和粗细，急不得，也补不回来。
5. 入窑釉烧：进窑二次烧成，温度上来后釉层熔融互渗，边界自然洇开。巩义窑一带的三彩就吃这一手，出窑才见真正的颜色。

资料来源：河南省文物考古研究院公开简报整理

## 碑刻拓片从洗石到上墨（c05）
- 分类：手作
- 难度：进阶
- 时长：20 分钟
- 关联遗址：s08
- 简介：一张纸贴进字口的凹槽，墨从淡到浓扑上好几遍。

步骤：
1. 清理石面：软毛刷清掉石面浮土和苔痕，字口里的泥要用竹签挑干净。手重了会伤到风化表层，所以只能轻，只能慢。
2. 润湿上纸：拓纸喷湿后覆上碑面，趁湿垫吸水纸，用排笔把空气赶出去，让纸贴进字口。纸要湿而不破，干了就揭不下来。
3. 敲纸入凹：棕刷反复敲打，把纸一点点砸进刻痕的凹槽里。这步偷懒，笔画边缘就会糊成一团，整张拓下来都是废的。
4. 逐层上墨：拓包蘸墨，先在别处试掉多余的，再从淡到浓一层层扑上去。忌一次下重，字口要靠三四遍才立得住。
5. 揭纸取拓：纸干到七八成，从一角缓缓揭下，快了会带破。摊平压两天才算成。黑底白字那一类走的是乌金拓的路子。

资料来源：龙门石窟世界文化遗产监测公开材料

## 嵩岳寺塔与斗拱的名字（c06）
- 分类：讲读
- 难度：入门
- 时长：12 分钟
- 关联遗址：s12
- 简介：从一座十二边形的砖塔讲起，把斗拱每个部件叫明白。

步骤：
1. 塔为何十二边：嵩岳寺塔的平面是十二边形，在早期砖塔里很少见。讲读把外来塔形和中原楼阁两条线并在一起，看它们怎么合成一座塔。
2. 密檐的叠法：塔身第一层很高，往上各层檐挤得紧密，全靠砖一层层叠涩出挑。砖不靠金属件，靠的是层层外挑把重量压回去。
3. 斗与拱之名：斗是方木块，拱是横出的短臂，两者交叉叠起托住檐口。一个叫法取自量器，一个叫法取自桥拱，拆开看就好记。
4. 出跳与铺作：拱往外挑一次算一跳，宋代文献里这一层叫铺作。跳数越多檐出得越远，斗拱也就慢慢从承重件往装饰件那边偏。
5. 用材分等：宋《营造法式》把用材分成等第，正殿用大材，次要房屋用小材。看斗拱的大小和跳数，大致能猜出它当初的身份。

资料来源：天地之中历史建筑群世界遗产公布材料

## 州桥：一座城的剖面（c07）
- 分类：影像
- 难度：入门
- 时长：9 分钟
- 关联遗址：s15
- 简介：九分钟短片，顺着发掘剖面往下走，看路摞路、桥摞桥。

步骤：
1. 脚下三米：镜头从开封今天的街面起步，往下切到地下数米，交代宋代御街与宫城的位置关系。剖面动画负责把三重城的叠压说清楚。
2. 桥身露头：州桥桥体从泥沙里一点点露出来，摄影机贴着桥面走，看清不同时期补砌的砖石差别，桥面上凹下去的那几道是车辙。
3. 河道读层：汴河剖面里淤积层一段水、一段泥反复叠加，画面标出曾经靠岸的位置，把《东京梦华录》里相关的句子贴在旁边。
4. 壁面石刻：推近两岸壁面上的海兽与云纹，用仿拓片的明暗处理让纹样立起来，说明这种整面石刻在同类发现里体量少见。
5. 夜市与河：结尾把州桥夜市复原成一段短动画，再切回现实里车来人往的同一条街口。黄河淤灌和一次次复建，是同一批人干的。

资料来源：河南省文物考古研究院州桥遗址公开资料整理

## 捏一个宋式泥塑小偶（c08）
- 分类：手作
- 难度：入门
- 时长：16 分钟
- 关联遗址：s14
- 简介：澄泥、塑胎、开脸，照着宋代市集上的小偶捏一个。

步骤：
1. 沉淀取泥：细泥加水搅浑，沉淀后取上层的细浆，晒干再揉。泥里掺一点棉絮，坯子阴干时就不容易开裂，这是老法子。
2. 捏塑大形：先捏出头和躯干的大形，头略大一点，宋式小偶的比例就在这一把里定下。泥一次拿够，中途补泥一定会留缝。
3. 接好四肢：手臂和腿单独搓成，接口抹泥刮毛再按上去。摆姿势只有这一下机会，等泥硬了只能砸掉重捏，别指望掰。
4. 开脸点睛：竹签压出眉眼，笔蘸稀泥浆点眼睛。开脸手要稳，前后三四下就够，改的次数一多，整张脸就糊得没法看。
5. 阴干罩彩：放进屋里慢慢阴干一周，别晒也别吹风。干透后刷一层白浆做底，衣纹的褶皱才吃得住颜色，最后再点眉。

资料来源：开封市文物部门公开资料与宋人笔记整理
