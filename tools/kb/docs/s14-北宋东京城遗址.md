# 北宋东京城遗址（s14）

- 别名：东京城
- 所在城市：开封
- 年代：宋
- 类型：都城遗址

## 摘要
北宋都城，因黄河淤积形成地下“城摞城”奇观。

## 简介
北宋东京城为当时世界上最大城市之一，外城、里城、宫城三重，以今开封老城区为中心。金元以降屡遭黄河决口淤灌，泥沙把宋代城市埋于今地表以下三至五米，形成历代城市上下叠压的“城摞城”景观。1981年以来考古勘察基本摸清外郭城轮廓与城门位置，州桥、汴河等发掘不断印证《东京梦华录》的记载。

## 考古发现
1981年起开封文物部门对东京外城、里城和古河道开展考古勘探，探明城墙基、城门与汴河走向，发现宋金时期官署基址与砖砌排水设施；州桥一带发掘（2018—2022）清理出历代路桥叠压层、河道与堤岸遗迹。

## 历史脉络
东京是北宋政治、经济与文化中心，瓦子、夜市与漕运百业辐辏，《清明上河图》即绘其市景；1126年靖康之变城破，北宋灭亡。城下叠压的多座城池是黄河水患与城市兴亡相互作用的直观样本。
