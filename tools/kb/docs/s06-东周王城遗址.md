# 东周王城遗址（s06）

- 别名：周王城
- 所在城市：洛阳
- 年代：周
- 类型：都城遗址

## 摘要
平王东迁后的周都城，城东有天子级王陵。

## 简介
东周王城位于今洛阳市区西部涧河与洛河之间，公元前770年周平王东迁后以此为都。上世纪五十年代起考古机构勘察出近长方形的城垣基址、宫殿区和大面积制陶、冶铸等手工业作坊区，形成宫庙与百工廛里并置的格局。城东周山一带有东周王陵大墓群及车马坑，印证了东周五百余年周天子都洛阳的史实。

## 考古发现
1955年起中国科学院考古研究所对洛阳东周城址系统调查勘探，探明王城墙基、门址、窖藏与作坊遗迹；其后在王城区域内发现大型建筑基址、陶文和空首布等遗物，城东王陵区勘察出带车马坑的高等级大墓。

## 历史脉络
东周王城是名义天下共主周王的城市中心，问鼎中原、王子朝之争等事件都发生在这座城里。它与成周城东西相对，是研究两周都城制度、手工业管理和王陵制度的实物基点。城中探出的冶铸与制陶作坊区，反映出周王室对手工业的官营管理。
