# 北阳平遗址（s02）

- 别名：北阳平
- 所在城市：三门峡
- 年代：仰韶
- 类型：聚落遗址

## 摘要
仰韶文化中晚期超大型中心聚落，发现罕见大房子基址。

## 简介
北阳平遗址位于灵宝市阳平镇，黄河以南的黄土台地上，是仰韶文化中晚期规模极大的中心聚落，面积超过百万平方米。遗址中部发现的大型房基室内面积两百余平方米，在同时期遗址中极为罕见，说明当时已出现较强的社会组织能力和等级分化。它与周边遗址群共同表明黄河中游在仰韶时代已有区域性聚落中心。

## 考古发现
1959年全国文物普查时登记发现，上世纪九十年代以来河南省文物考古研究院、北京大学等多次调查勘探，发现房基、壕沟、墓葬和大量彩陶、石器、骨器，其中大房基F301单间面积居同期建筑前列，被认为具有公共礼仪性质。

## 历史脉络
北阳平把中国史前大型中心聚落的实例提前到仰韶时代，为研究黄河中游社会复杂化、聚落层级和文明起源提供了关键材料，也是探讨夏文明前身的重要一环。这里发现的大型建筑和丰富遗物说明三门峡一带的黄河岸边在史前已有很高的聚落发展水平。
