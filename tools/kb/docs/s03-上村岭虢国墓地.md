# 上村岭虢国墓地（s03）

- 别名：虢国墓地
- 所在城市：三门峡
- 年代：周
- 类型：墓葬群

## 摘要
西周晚期至春秋初虢国贵族墓地，出土玉柄铁剑。

## 简介
上村岭虢国墓地位于三门峡市区上村岭，是西周晚期至春秋早期虢国国君及贵族的邦国墓地，紧邻虢国都城遗址。1956年起中国科学院考古研究所发掘清理墓葬二百余座、车马坑多座，出土大批有铭青铜器和数千件玉器。它是我国发现的布局最完整、等级序列最清晰的西周诸侯墓地之一，证实了文献中虢国在三门峡一带的史实。

## 考古发现
1956至1958年发掘上村岭墓群及车马坑，出土大量青铜礼乐器、玉器和铁器。1990至1991年河南省文物考古研究所等单位再发掘虢仲墓等高等级墓，出土玉柄铁剑——我国已知最早的人工冶铁制品之一，以及石排箫、缀玉面罩等。

## 历史脉络
虢国为姬姓诸侯国，世代与周王室关系密切，春秋初年为晋所灭。墓地的列鼎列器制度与车马陪葬，是研究西周礼乐制度和虢国历史的第一手资料，据此建成的虢国博物馆填补了两周诸侯国考古展示的空白。
