# 嵩岳寺塔（s12）

- 别名：嵩岳寺塔
- 所在城市：郑州
- 年代：汉唐
- 类型：古建筑

## 摘要
北魏建塔，中国现存最古老的高层砖塔。

## 简介
嵩岳寺塔位于登封市嵩山南麓，建于北魏（一般定为公元523年前后），塔身十五层、高约四十米，平面十二边形，密檐式砖构，下收上叠，融合印度窣堵坡与中国楼阁形制。它是中国现存时代最早、保存最完好的高层砖塔。嵩岳寺相传始建于晋代，北魏时鼎盛，2010年该塔作为“天地之中”历史建筑群组成部分列入世界遗产。

## 考古发现
塔历代屡见修葺，二十世纪八十年代进行测绘与抢险加固，查明了塔体砖砌做法、底层塔心室形制与基座结构；塔身第一层各面嵌饰砖雕佛龛、狮兽等。寺内遗留各期碑刻与建筑遗迹，为研究塔寺沿革提供了实物依据。

## 历史脉络
嵩岳寺塔建于北魏佛教鼎盛期，其形制开中国楼阁式密檐砖塔之先河，是研究北魏建筑技术、佛教传播与外来文化交融的孤例标本，也是中原古代工程抗震成就的代表。塔历经多次地震仍基本保持原貌，是北魏建筑难得的传世实例。
